## Unit of analysis
One **utterance/event**, not one chapter. Keep narrator, speaker, observed agent, interpreter, and present researcher separate.

| Field | Meaning |
|---|---|
| event_id | Stable event identifier |
| passage_locator | Edition + page/line or chapter; never inferred |
| narrator | Source reporting the utterance/event |
| focal_observer | Whose viewpoint is represented |
| observer_state | What text explicitly says about their condition |
| perceived_signal | What the observer reports perceiving |
| attributed_source | Whom the observer believes generated the signal |
| interpretation | Inference by observer, clearly distinguished from event |
| action | What the observer does |
| response | Subsequent event, not automatically causal |
| external_observers | Other perspectives and their stated evidence |
| translation_variance | Differences among witnesses/translations |
| textual_status | Verified / paraphrase / unverified |
| hypothesis | Separately stated XOcortex/RCME prediction |
| unresolved_holes | Named questions whose identity/reference remains unresolved |
